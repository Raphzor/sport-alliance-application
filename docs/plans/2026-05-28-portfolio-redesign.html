Sport Alliance Portfolio — Redesign Plan

2026-05-28 v1 · Single-file static page · One-time use for application
Goal. Rebuild raphael_mello_sportalliance.html so it does not look AI-generated. The current page hits every 2024–25 AI-design fingerprint: dark mode + cyan/blue glow, monospace tags, identical card grids, emoji icons, gradient hovers, grid noise overlay, watermark text. For an AI Systems Lead role, that surface reads as "I had Claude build my portfolio" — which is the one impression to avoid. We pivot to a light editorial / Swiss-magazine direction: confident typography, generous whitespace, asymmetric layout, restrained palette, zero glow.
Stack
LayerTechnologyNotes
Document HTMLCSSvanilla JS Single self-contained file. No build step. Hosted statically or sent as attachment.
Typography GT Sectra or Fraunces + ABC Diatype or Inter Tight Editorial serif display + clean sans body. Both available on Google Fonts (Fraunces + Inter Tight) for zero-cost.
Palette paper #f4f1eaink #15110daccent #c0392b Warm off-white paper, near-black ink, single oxblood accent used sparingly. No blue, no teal, no gradients.
Layout CSS Grid12-colasymmetric Editorial grid. Content lives in unequal columns. Break the grid at the hero and the Atlas pull-quote.
Motion none / minimal Drop the fadeUp animations. A confident, static page is more senior than an animated one.
Phases
PHASE 1 Strip the AI tells Delete grid overlay, gradients, emoji icons, monospace labels, dark theme, watermark, hover translateY.
PHASE 2 Establish system New tokens, fonts (Fraunces + Inter Tight), light palette, type scale, asymmetric grid.
PHASE 3 Rebuild the hero Lead with the claim, not the name. One headline that earns the meeting. Add CTA.
PHASE 4 Body, Atlas, timeline Asymmetric "fit" section, editorial Atlas pull-quote, restrained timeline, fix duplicated "Languages".

2.1 Swap the Google Fonts link and define new tokens
Files
~ modified <head> link tag, :root
Step 1 · Replace the Google Fonts <link>
html — REPLACE the existing link tag in <head>
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Fraunces:opsz,wght,SOFT@9..144,300..800,0..100&family=Inter+Tight:wght@300;400;500;600&display=swap" rel="stylesheet">

Fraunces is a contemporary editorial serif with optical-size axes — it shines at headline sizes and stays legible at body. Inter Tight is the same family the design world has standardised on without the AI baggage of regular Inter (it's tighter, slightly more editorial).
